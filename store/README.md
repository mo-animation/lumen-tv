# رفع Lumen Player على LG Content Store

اسم Lumen كان مستخدم لتطبيق تاني على الستور، فنسخة الستور اسمها **Lumen Player**. نسختك اللي على التلفزيون فضلت اسمها Lumen.

كل اللي محتاجه للتقديم موجود في الفولدر ده:

| الملف | استخدامه |
|---|---|
| `io.github.mo-animation.lumen_<version>_all.ipk` | ملف التطبيق اللي بيترفع |
| `images/` | الأيقونة 400×400، و6 صور شاشة 1280×720، وخلفية الـ Launcher، وصورة الـ Splash |
| `docs/Lumen_Self_Checklist_5.0.xlsx` | الـ Self-Checklist بتاع LG (نسخة 5.0) متملي |
| `docs/Lumen_UX_Scenario_4.3.pptx` | الـ UX Scenario على قالب LG (نسخة 4.3) |
| `LISTING.md` | كل خانة في فورم Seller Lounge واللي يتكتب فيها |

## نسخة الستور بتفرق في إيه عن نسخة التلفزيون

- **App ID مختلف** (`io.github.mo-animation.lumen`)، فالنسختين ممكن يتسطبوا جنب بعض.
- **مفيش أبديت تلقائي من GitHub.** أي تعديل لازم يترفع لـ LG ويتراجع من الأول.
- **مفيش تجديد لـ Developer Mode.**
- **زرار Back في أول شاشة بيوديك على Home التلفزيون علطول**، لأن LG بتشترط كده. في نسخة التلفزيون لسه محتاج تدوس مرتين.

نسختك اللي على Developer Mode شغالة زي ما هي، وبتاخد التحديثات أول بأول.

## الخطوات

### 1. قبل ما تقدّم
- [ ] ابحث في **LG Content Store** عن **Lumen Player** واتأكد إن مفيش تطبيق بنفس الاسم، لأن LG بترفض الأسماء المكررة.
- [ ] جرّب نسخة الستور المتسطبة على التلفزيون دلوقتي (اسمها **Lumen Player**، وهي النسخة اللي من غير حسابك):
  - [ ] Back في أول شاشة يوديك على Home التلفزيون
  - [ ] الماوس بتاع الريموت والعجلة شغالين في كل الشاشات
  - [ ] زرار الميكروفون في كيبورد LG بيكتب في خانة السيرفر
  - [ ] زرار EXIT بيقفل التطبيق، والأزرار الملونة والأرقام مش بتعمل حاجة غلط
  - [ ] اكتب `mo-animation.github.io/lumen-tv/qa.m3u` في أول خانة، ودوس Connect، وشغّل قناة وفيلم وحلقة
- [x] اسمك وإيميلك مكتوبين في أول صفحة من الـ UX Scenario. الملف ده متسجل في `.gitignore` ومش بيترفع على GitHub لأن الريبو public، فهو موجود على الماك بس.

### 2. حساب البائع (لازم تعمله بنفسك)
1. ادخل [LG Seller Lounge](http://seller.lgappstv.com) بحساب LG بتاعك.
2. سجّل كـ **Individual Seller**.

### 3. ملف التطبيق
اعمل build للنسخة بعد آخر تعديل:
```bash
node tools/store.js
```
الملف بيطلع في الفولدر ده، ورقم النسخة بيبقى نفس رقم نسخة التلفزيون.

### 4. التقديم
من **App Management → App Submission**، واملا الخانات من `LISTING.md`:
- File Upload: ملف الـ ipk
- Images: الصور اللي في `images/`
- Service Info: الوصف والتصنيف ورابط الدعم
- Test Info: ملفي الـ checklist والـ UX Scenario، ونص حساب التجربة

### 5. بعد الموافقة
كل تحديث بعد كده:
1. `node tools/store.js`
2. ارفع الـ ipk الجديد كإصدار جديد في Seller Lounge.
3. حدّث رقم النسخة في الـ UX Scenario والـ checklist.

رقم النسخة لازم يكبر كل مرة، لأن LG مش بتقبل نفس الرقم مرتين.
